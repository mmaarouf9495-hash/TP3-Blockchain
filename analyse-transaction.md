# Analyse détaillée d'une transaction Bitcoin sur TestNet4

## 1. Présentation du projet

Ce projet consiste à analyser une transaction Bitcoin réalisée sur le réseau TestNet4 afin de comprendre son fonctionnement et les différentes étapes de son exécution.

## 3. Analyse des entrées (Inputs)

Les entrées représentent les UTXO utilisés pour financer la transaction. Elles indiquent les fonds utilisés par l'expéditeur.

## 4. Analyse des sorties (Outputs)

Les sorties représentent les montants envoyés aux destinataires. Elles peuvent également inclure une sortie de monnaie rendue à l'expéditeur.

## 5. Frais de transaction

Les frais sont calculés selon la formule suivante :

Frais = Total des entrées - Total des sorties.

## 6. Confirmations

Les confirmations représentent le nombre de blocs ajoutés après l'inclusion de la transaction dans la blockchain.

## 7. Conclusion

Cette analyse permet de comprendre le fonctionnement d'une transaction Bitcoin, notamment les entrées, les sorties, les frais et le mécanisme des UTXO.
