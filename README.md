# Analyse d'une transaction Bitcoin sur TestNet4

## 1. Présentation du sujet

Ce projet porte sur l'analyse du fonctionnement d'une transaction Bitcoin sur le réseau TestNet4.

## 2. Objectifs du projet

- Comprendre le fonctionnement d'une transaction Bitcoin.
- Identifier les entrées (Inputs) et les sorties (Outputs).
- Comprendre les frais de transaction.
- Expliquer les confirmations.
- Comprendre le mécanisme des UTXO.

## 3. Méthodologie

Ce travail repose sur une étude documentaire et l'analyse d'une transaction Bitcoin réalisée sur TestNet4.

## 4. Résultats attendus

Présenter les différentes étapes d'une transaction et expliquer les éléments qui la composent.
